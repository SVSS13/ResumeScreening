# ADR-006: Cross-Platform Memory Telemetry & Adaptive Epoch-Aware Upstream Rate Limiting

## Status
Accepted

## Context
1. **Memory Telemetry Inconsistencies (Finding A4)**: `MemoryGuard` previously read `/proc/self/statm` directly or relied on POSIX `resource.getrusage()`. However, `/proc/self/statm` is Linux-only, and `resource.ru_maxrss` has platform-dependent units (Kilobytes on Linux/BSD, but raw bytes on macOS Darwin). On Windows, `resource` is unavailable entirely. If `psutil` is missing on macOS or Windows, memory calculation would either overestimate by 1024× or raise exceptions, crashing `/health`.
2. **Upstream Quota Reset Calculation (Finding A10)**: GitHub's API enforces strict rate limits (60 unauthenticated req/hr), returning HTTP 403/429 with `x-ratelimit-reset: <epoch_seconds>`. The previous implementation hardcoded a 10-second pause rather than calculating the delta to the reset timestamp, leading to premature retries and secondary 403 blocks.

## Decision
1. **Multi-Tier Cross-Platform RSS Detection**:
   - Primary: `psutil.Process().memory_info().rss` in MB (if installed).
   - Linux POSIX: Read `/proc/self/statm` pages × `SC_PAGE_SIZE`, fallback to `resource.ru_maxrss / 1024.0` (KiB).
   - macOS Darwin: `resource.ru_maxrss / (1024.0 * 1024.0)` (bytes).
   - Windows/Unknown: Return `0.0` with a warning log, disabling proactive memory eviction while allowing the server and `/health` to run without crashing.
2. **Dynamic Epoch-Based Outbound Throttling**:
   - `OutboundLimiter.observe()` parses `x-ratelimit-reset` as a UNIX epoch timestamp:
     $$\text{pause\_seconds} = \max(0.0, \text{float}(\text{reset\_ts}) - \text{time.time()})$$
   - `_paused_until` is updated dynamically under `asyncio.Lock`.
   - When quota is exhausted, candidate resumes are scored using offline features, recording `status="rate_limited"` without aborting the batch.

## Consequences
- **Positive**: Zero platform crashes on macOS and Windows; `/health` endpoint remains 100% resilient.
- **Positive**: GitHub rate limits respect upstream resets precisely, eliminating ban escalation.
- **Trade-off**: On minimal Windows installations without `psutil`, memory hysteresis eviction defaults to passive mode (relying on per-shard item and byte bounds).
